# 異世界BGM25Timer

BGM付きのポモドーロタイマー（時間は調整可能）。25分の作業・5分の休憩サイクルでカウントダウンしながら、時間帯やフェーズに応じてBGMを切り替えられる。タイマーが本体、BGMはそれを支える付随機能。BGMが必要ない場合は、音量を０に。

## 使い方

1. フェーズ（[朝/昼/夜]）ボタンを押すと選曲
2. 「25分」ボタンで作業タイマーが、「５分ボタン」で休憩タイマーが開始、対応する作業用BGMが再生される（時間変更可能）
3. 「ループボタン」では作業曲→休憩曲用BGMセットに切り替わり、右横のボタンで回数指定可能
4. 必要に応じて自然音（雨・波など）をそれぞれのBGMに重ねられる
5. BGMは再生スピードの変更は 0.5 ずつ 0.75 ~ 1.25 倍まで。再生中でも変化。タイマー時間は変更されない
6. タイマー終了音はチェックを外せばオフにできる

## 技術構成

- HTML / CSS / JavaScript（フレームワーク・ビルドツールなし）
- Web Audio API によるクロスフェード・ループ制御
- localStorage（設定の保存のみ、外部送信なし）
- GitHub Pages でホスティング

## 音源について

本アプリで使用しているBGMは、各作曲者のホームページ等から個別に取得したフリー音源。曲名・作曲者名・取得元URL・ライセンス種別・取得日は [CREDITS.md](./CREDITS.md) を参照。

音源ファイル単体での再配布・販売は行っていない。本アプリの機能（BGM付きタイマー）に組み込んで利用する形にとどめている。
